Data Access

Shared data files are in the data/ directory. Individual document pages offer TSV annotation downloads via the toolbar.

  • slinks.json — cross-lingual sentence alignments
  • sent-{lang}.json — sentence text per language
  • wn-defs-{lang}.json — WordNet definitions
  • wn-syns-{lang}.json — WordNet synonyms
  • manifest.json — available languages and features
